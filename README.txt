# Meet & STEM Countdown Page

## Instructions to Set Your Target Release Date:
1. Open `index.html` in any code editor (e.g., VS Code).
2. Look for line 160:
   `const TARGET_DATE_STRING = "2026-09-01T18:00:00";`
3. Replace `"2026-09-01T18:00:00"` with your desired publication date and time (formatted as `YYYY-MM-DDTHH:MM:SS`).
4. Save the file and host it on your server, Vercel, Netlify, or GitHub Pages.

Every time a user visits the website, the random matrix-style character shuffle animation will run for 2.5 seconds before revealing the exact remaining time until your post release.
